# 💈 Barber Club

---

## 🧩 Sobre o projeto
O **Barber Club** é uma landing page moderna e de alta conversão desenvolvida para o nicho de barbearia. O foco principal foi criar uma interface que transmita confiança e profissionalismo, unindo um design limpo a uma navegação intuitiva. A página apresenta a experiência, os serviços, equipe, depoimentos de clientes e uma seção de contato.

A interface é totalmente responsiva, adaptando-se perfeitamente de desktops a dispositivos móveis, com foco especial em performance e acessibilidade.

---

## 🎯 Objetivo do projeto
O projeto tem como foco:

- Semântica: Utilizar corretamente tags HTML5 para SEO e acessibilidade.

- Responsividade: Utilizar propriedades CSS junto a Grid e Flexbox para responsividade Mobile e Desktop.

- Classes utilitárias e reutilizáveis: Criar classes reutilizáveis para seções de conteúdo, cards de serviços, depoimentos e de equipe.

- UI/UX: Utilizar o Figma para construção do Design, aplicando contrastes, hierarquia visual e CTAs estratégicos.

- Features de Componentes: Aplicar a feature de um Menu Hamburguer para Mobile.

---

## 🚀 Tecnologias utilizadas
- HTML5 (Semântico e Acessível)

- CSS3 (Flexbox, Grid e Variáveis)

## 📋 Funcionalidades principais

- Menu Hamburguer Responsivo: Navegação fluida para dispositivos móveis.

- Acessibilidade: Uso de atributos ARIA, tags de endereço (Address) e tags de tempo (datetime) para leitores de tela.

- Seção de Review: Cards de depoimentos com fotos e nomes reais dos clientes.
